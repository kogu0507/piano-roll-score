# 教室試用メモテンプレート

このテンプレートは、`piano-roll-score` を先生、生徒、保護者などに試してもらうときの記録用である。

個人情報は書かなくてよい。名前の代わりに「生徒A」「先生B」のように記録する。

```text
使用ブラウザ:

試用時間:
```

## 2. 利用者の属性

```text
年齢層:
ピアノ経験:
楽譜を読めるか:
普段使う端末:
```

例:

- 年齢層: 小学校低学年
- ピアノ経験: 3か月
- 楽譜を読めるか: まだ難しい
- 普段使う端末: 保護者のスマートフォン
