# 第20段階 手動確認チェックリスト

対象: 教室カタログ導線短縮と直接練習ボタン

## 1. ホーム画面の入口

- [ ] ホーム画面上部に「サンプル曲」の曲選択、ピアノ表示、スコア表示、曲カタログが表示される。
- [ ] ホーム画面上部に「教室コード」の入力欄と「教室カタログを開く」が表示される。
- [ ] 教室コード入力には、先生から聞いたコードで教室専用カタログを開く機能だと分かる短い説明がある。
- [ ] 「データ管理」は初期状態で折りたたまれている。
- [ ] 「データ管理」内に教室コード入力が重複して残っていない。
- [ ] 「データ管理」内には、catalog.json URL直接入力、JSON貼り付け、JSONファイル読み込み、JSON書き出し、端末内保存が残っている。

## 2. 教室カタログ主役表示

- [ ] `demo` を入力して「教室カタログを開く」を押すと、デモ教室カタログが表示される。
- [ ] `?classroom=demo` で開くと、教室カタログが画面上部から主役として表示される。
- [ ] 教室名、カタログ名、更新日が分かる。
- [ ] 通常のサンプル曲選択、JSON編集欄、端末保存欄が先に目立ちすぎない。
- [ ] 「サンプル曲へ戻る」または同等の戻る操作で、通常のホーム表示へ戻れる。

## 3. 教室カタログカード

- [ ] 曲名、説明、グループ、levelが読みやすく表示される。
- [ ] 各カードに「ピアノ表示」と「スコア表示」が表示され、押しやすい。
- [ ] `demo-001` の「ピアノ表示」から直接ピアノ表示へ進める。
- [ ] `demo-902` の「スコア表示」から直接スコア表示へ進める。
- [ ] 必要に応じて「JSONを確認」から曲JSONを確認できる。
- [ ] 「JSONを確認」から開いた場合、既存のJSON編集欄へ曲JSONが反映される。

## 4. 既存導線

- [ ] 内蔵曲の選択からピアノ表示へ進める。
- [ ] 内蔵曲の選択からスコア表示へ進める。
- [ ] 通常の `catalog.html` が開ける。
- [ ] `?id=001` と `?id=902` が従来どおり開ける。
- [ ] `?catalog=./data/classroom-catalogs/demo/catalog.json` が従来どおり動く。
- [ ] JSON貼り付け、JSONファイル読み込み、JSON書き出し、端末内保存、保存曲読み込みが壊れていない。

## 5. レスポンシブ

- [ ] スマートフォン縦向きで、教室コード入力が見つけやすい。
- [ ] スマートフォン縦向きで、教室カタログカードと直接練習ボタンが横スクロールなしで使える。
- [ ] スマートフォン横向きで、教室カタログカードが画面外へはみ出さない。
- [ ] Androidタブレット相当で、カードとボタンが押しにくくならない。
- [ ] Windowsタブレット相当で、ホームと教室カタログが横スクロールなしで使える。

## 6. 今回実装しないことの確認

- [ ] 教室カタログ検索、グループ折りたたみ、グループフィルターはない。
- [ ] 最近使った教室、教室コード履歴保存、自動保存はない。
- [ ] ログイン、サーバー認証、先生用管理画面、クラウド同期はない。
- [ ] 音源再生、演奏判定はない。
