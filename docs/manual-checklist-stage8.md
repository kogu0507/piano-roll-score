# 第8段階 ユーザー確認手順

確認状態: 実装前。実装スレッドの完了後に使用する。

## 1. この確認の目的

端末内保存と設定保存が、初心者にも分かりやすく安全に使えるか確認する。

この段階の保存は、その端末のブラウザ内だけで使う。別の端末へ自動同期されない。ブラウザのデータ削除やプライベートブラウズでは消える可能性があるため、重要なデータはJSON書き出しも使う。

## 2. PCでの確認

通常は次のURLを開く。

```text
http://127.0.0.1:5173/app/?id=001
```

### 手順1: 楽曲を端末内へ保存する

ロード画面または楽曲画面で、現在の楽曲を端末内へ保存する。

正常な状態:

- 利用者の操作なしに自動保存されない。
- 保存ボタンまたは同等の明示的な操作で保存される。
- 保存後、曲名と保存日時が分かる。
- 端末内だけの保存であることが画面上で分かる。

確認すること:

- 「どこに保存されたか」が分かりやすいか。
- クラウド保存やアカウント保存と誤解しないか。

### 手順2: 保存一覧から読み込む

保存一覧を開き、保存した曲を読み込む。

正常な状態:

- 保存した曲が一覧に表示される。
- 曲名、保存日時が表示される。
- 読み込み後、既存と同じ検証フローを通り、縦表示・横表示へ進める。

確認すること:

- 保存一覧から目的の曲を選びやすいか。
- 読み込み操作が分かりやすいか。

### 手順3: ページ再読み込み後も保存データが残るか

ブラウザでページを再読み込みする。

正常な状態:

- 保存一覧に保存済みの曲が残っている。
- 保存曲を再度読み込める。

確認すること:

- 「端末内に保存された」と感じられるか。

### 手順4: 保存曲を削除する

保存一覧から保存曲を削除する。

正常な状態:

- 削除前に確認が出る。
- キャンセルした場合は削除されない。
- 削除を確定した場合は一覧から消える。

確認すること:

- 誤って消しにくいか。
- 削除されたことが分かりやすいか。

### 手順5: 表示・再生設定が復元されるか

次のような設定を変更する。

- 縦表示の白鍵幅
- 縦表示の横位置
- 横表示の五線間隔
- 横表示の譜面縦位置
- 再生速度
- メトロノームON/OFF
- メトロノーム音量
- プリカウント

その後、ページを再読み込みする。

正常な状態:

- 保存対象の設定が復元される。
- 壊れた設定値があっても、アプリが止まらず初期値へ戻る。
- 再生中の現在位置や読み込んだだけの楽曲が、勝手に永続保存されたようには見えない。

確認すること:

- 次回起動時に使いやすくなっているか。
- 何が保存されるのか分かりにくくないか。

## 3. スマートフォンでの簡易確認

スマートフォンで同じ画面を開く。

```text
http://192.168.0.162:5173/app/?id=001
```

確認すること:

1. 楽曲を端末内へ保存できる。
2. 保存一覧から読み込める。
3. ページ再読み込み後も保存曲が残る。
4. 保存曲を削除できる。
5. 縦表示の白鍵幅や横位置が再読み込み後も復元される。
6. 横スクロールや操作しにくいボタンがない。

## 4. 確認結果の伝え方

次の形式で設計スレッドへ伝える。

```text
1. 楽曲を端末内へ保存できた: はい / いいえ
2. 保存後に曲名と保存日時が分かる: はい / いいえ
3. 端末内だけの保存だと理解できる: はい / いいえ
4. 保存一覧から読み込めた: はい / いいえ
5. ページ再読み込み後も保存曲が残った: はい / いいえ
6. 削除確認と削除操作: 問題なし / 問題あり
7. 縦表示の白鍵幅・横位置設定の復元: 問題なし / 問題あり
8. 横表示の五線間隔・譜面縦位置設定の復元: 問題なし / 問題あり
9. 再生速度・メトロノーム・プリカウント設定の復元: 問題なし / 問題あり
10. JSON書き出し案内の分かりやすさ: 問題なし / 問題あり
11. スマートフォン表示: 問題なし / 問題あり / 未確認

使用したPCブラウザ:
使用したスマートフォン:
使用したスマートフォンブラウザ:
分かりにくかったところ:
改善してほしいところ:
```

「問題あり」の場合は、どの操作で起きたか、期待した動き、実際の動きを分かる範囲で伝える。
