## 1. この確認の目的

練習画面で、譜面Canvasとよく使う操作が画面の主役になっているか確認する。

第9.5段階では、単に画面幅へ収まるだけでなく、スマートフォンやタブレットを鍵盤付近へ置いたときに、実鍵盤を見ながら白鍵幅や譜面位置を調整できるかを重視する。

端末別レイアウト補正後は、スマートフォン、Androidタブレット、Windowsタブレット、PCで、同じ機能を保ちながら画面サイズに合った配置になっているかを確認する。

追加補正後にも維持する通常練習モード:

```text
練習画面
├─ 最小操作列
│  ├─ ▶ 再生
│  ├─ ❚❚ 一時停止
│  ├─ ⏮ 先頭へ
│  └─ ☰ 練習メニュー
├─ 速度と現在位置
│  ├─ 再生速度セレクト
│  └─ 曲の現在位置シークバー
└─ Canvas
```

Canvasは、実際のピアノ鍵盤に近い画面下側へ大きく表示されることを重視する。ボタンや再生速度欄がCanvasを圧迫しないことを確認する。

追加補正後に期待する表示調整モード:

```text
表示調整モード
├─ Canvasは通常練習画面と同じ位置・大きさで固定
└─ Canvas上に半透明のフローティングパネル
   ├─ 閉じる
   ├─ 縦表示の場合
   │  ├─ 白鍵1鍵の幅
   │  ├─ 譜面の横位置
   │  └─ 音価の幅
   └─ 横表示の場合
      ├─ 五線の1間の幅
      ├─ 譜面の縦位置
      └─ 音価の幅
```

音価の幅は、再生速度やBPMではなく、Canvas上の時間方向の表示密度である。値を小さくすると、音符ブロックの時間方向が圧縮され、速いテンポでも目で追いやすくなる。

端末別レイアウト補正後に期待する表示調整モード:

- スマートフォン縦向きでは、Canvasを見ながら調整できる小さなフロートまたは同等のUIになっている。
- スマートフォン横向きでは、フロートがCanvas全域を覆わず、再生ボタン列付近を含む画面上部へ寄っている。
- PC、Windowsタブレット、Androidタブレットでは、スマートフォン用の詰め込み表示ではなく、サイド寄せまたは小型フロートでCanvasを見ながら調整しやすい。
- 表示調整フロートの背景は半透明で、背後のCanvasが見える。
- 文字、スライダー、ボタンは読める。
- 音価の幅が最初から見つけやすい。

追加補正後にも維持する練習メニュー:

```text
練習メニュー
├─ 再生設定
│  ├─ 再生速度
│  ├─ メトロノーム
│  ├─ メトロノーム音量
│  └─ プリカウント
├─ 表示設定
│  ├─ 表示調整モードを開く
│  ├─ 縦表示 / 横表示へ切り替え
│  └─ 曲情報
└─ その他
   ├─ 端末内に保存
   ├─ JSONを書き出す
   ├─ 保存一覧を開く
   └─ ロード画面へ戻る
```

端末別レイアウト補正後に期待する練習メニュー:

- スマートフォンでは、画面幅100%の全面メニューに固定されていない。
- 80%程度のドロワー、または同等に閉じやすいUIになっている。
- メニュー外の背景部分をタップする、固定された閉じるボタンを押す、などで下の方を操作した後でもすぐ閉じられる。
- PCとタブレットでは、画面幅を活かして読みやすく、押しやすい。

## 2. PCでの確認

通常は次のURLを開く。

```text
http://127.0.0.1:5173/app/?id=001
```

### 手順1: 縦表示の練習画面を確認する

縦表示を開く。

正常な状態:

- 最小操作列に、再生、一時停止、先頭、練習メニューの4つが1列で並んでいる。
- 4つのボタンが文字中心ではなく、アイコン中心でコンパクトに表示されている。
- 再生速度が大きなrangeではなく、プルダウンまたは同等のコンパクトUIになっている。
- 曲の現在位置シークバーが低背の1行UIで、Canvasを圧迫しない。
- Canvasが画面下側へ大きく表示されている。
- 曲名、縦/横切り替え、表示調整スライダーが通常練習画面を圧迫していない。
- ロード画面へ戻る操作が、練習中に誤って押しにくい位置にある。

確認すること:

- その曲を練習するために必要な操作が、探さずに使えるか。
- Canvasが実際のピアノ鍵盤に近い位置へ表示されているか。
- 画面を少し動かしても、ブラウザのプルダウン更新が起きにくいか。

### 手順2: 縦表示の表示調整モードを確認する

練習メニューから表示調整モードを開く。

正常な状態:

- 白鍵1鍵の幅と譜面横位置を、Canvasを見ながら調整できる。
- 表示調整パネルが半透明のフロートとしてCanvas上に重なり、Canvas自体を押し下げない。
- PCやタブレットでは、サイド寄せまたは小型フロートによりCanvasを広く見ながら調整できる。
- 音価の幅を変更すると、再生速度を変えずに音符ブロックの時間方向の長さと移動量が変わる。
- 調整後に閉じる操作で通常練習モードへ戻れる。
- 閉じても調整値が維持される。

### 手順3: 横表示の練習画面を確認する

横表示へ切り替える。

正常な状態:

- 最小操作列、再生速度、曲の現在位置シークバーが縦表示と同じ考え方でコンパクトに配置されている。
- Canvasが画面下側へ大きく表示されている。
- 縦表示へ戻る操作が練習メニュー内で見つかる。

確認すること:

- 横表示で五線風の見やすさが維持されているか。
- Canvasと操作欄の優先順位が縦表示と同じで分かりやすいか。

### 手順4: 横表示の表示調整モードを確認する

練習メニューから表示調整モードを開く。

正常な状態:

- 五線の1間の幅と譜面縦位置を、Canvasを見ながら調整できる。
- 表示調整パネルが半透明のフロートとしてCanvas上に重なり、Canvas自体を押し下げない。
- PCやタブレットでは、サイド寄せまたは小型フロートによりCanvasを広く見ながら調整できる。
- 音価の幅を変更すると、再生速度を変えずに音符ブロックの横方向の長さと移動量が変わる。
- 調整後に閉じる操作で通常練習モードへ戻れる。
- 閉じても調整値が維持される。

### 手順5: 練習メニューを確認する

メニュー、ハンバーガーメニュー、または折りたたみ領域を開く。

正常な状態:

- スマートフォンでもメニューが画面内に表示される。
- メニュー内部をスクロールすれば全項目へ到達できる。
- スマートフォンでは、背景タップ、固定閉じるボタン、または同等の操作で、下の方を操作した後でもすぐ閉じられる。
- 再生設定、表示設定、その他の順に並んでいる。
- 再生速度、メトロノーム、音量、プリカウントが深い階層なしに見つかる。
- 表示調整モード、縦/横切り替え、曲情報が表示設定にまとまっている。
- 保存、JSON書き出し、保存一覧、ロード画面へ戻る操作がその他にまとまっている。
- メニューを閉じられる。

確認すること:

- 再生設定の方が保存やJSON書き出しより先に見えるか。
- 階層が深すぎず、練習中に使いやすいか。

## 3. スマートフォンでの確認

スマートフォンで同じ画面を開く。

```text
http://192.168.0.162:5173/app/?id=001
```

確認すること:

1. 通常練習モードでCanvasが画面下側へ大きく表示される。
2. 再生、一時停止、先頭、練習メニューが1列に収まっている。
3. 4つの操作ボタンがアイコン中心で、Canvasを圧迫していない。
4. 再生速度がプルダウンまたは同等のコンパクトUIになっている。
5. 再生速度に 2倍、1.75倍、1.5倍、1.25倍、1倍、0.75倍、0.5倍 がある。
6. 曲の現在位置シークバーが低背で、隠れず操作しやすい。
7. 曲名や縦/横切り替えが通常練習画面を圧迫していない。
8. 練習メニューが画面内に表示され、全項目へ到達できる。
9. 練習メニューの下の方を操作した後でも、すぐ閉じられる。
10. 表示調整モードを開ける。
11. 表示調整モードでCanvasが押し下げられず、半透明フロート越しにCanvasを見られる。
12. スマートフォン横向きで、表示調整フロートがCanvas全域を覆っていない。
13. 音価の幅が見つけやすい。
14. 縦表示で白鍵幅と譜面横位置を調整しやすい。
15. 横表示で五線間隔と譜面縦位置を調整しやすい。
16. 音価の幅を小さくすると、音符の時間方向の移動が目で追いやすくなる。
17. 表示調整モードを閉じて通常練習モードへ戻れる。
18. 練習メニューが再生設定、表示設定、その他の順で分かりやすい。
19. 画面移動時にプルダウン更新が起きにくい。
20. 端末回転後も大きく崩れない。
21. ページ全体の横スクロールがない。

## 4. タブレットでの確認

タブレットがある場合は、縦向きと横向きで確認する。

タブレットがない場合は未確認でよい。

確認すること:

- Canvasが広く使えているか。
- 主要操作が遠すぎないか。
- 縦表示で1オクターブ前後の課題を鍵盤へ合わせやすそうか。
- 横表示で五線風表示と操作欄のバランスがよいか。
- スマートフォン用の詰め込み表示ではなく、タブレットの画面幅を活かせているか。
- WindowsタブレットやAndroidタブレットでも押しやすいか。
