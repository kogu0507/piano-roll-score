# 第10段階 ユーザー確認手順

確認状態: 第9.5段階までの主要レイアウト確認は完了。次はMVPとして教室で試す前の仕上げ確認を行う。

## 1. この確認の目的

第10段階は、大きな新機能を追加する段階ではない。

目的は次の3つである。

1. MVP完成条件を満たしているか確認する。
2. 教室で先生や生徒に試してもらう前に、操作不能な箇所や説明不足を減らす。
3. 試用時に、教育的価値と改善点を記録できる状態にする。

この段階では、演奏判定、ピアノ音源再生、MIDI入力、マイク入力、クラウド同期、生徒管理は確認対象にしない。これらはMVP対象外または将来検討である。

## 2. 実装スレッド完了後に確認すること

実装スレッドが第10段階のMVP監査と仕上げを完了したら、まず完了報告をこの設計スレッドへ貼り付ける。

次に、`docs/mvp-readiness-checklist.md` を開き、要注意事項を確認する。特に、音名と指番号の表示切替UI、iPhone Safariの未確認、教室での教育的有効性は、教室試用前または試用時に判断する。

その後、次の確認を行う。

## 3. 基本動作の確認

通常は次のURLを開く。

```text
http://127.0.0.1:5173/app/?id=001
```

スマートフォンやタブレットでは、設計スレッドが案内するLAN用URLを開く。

確認すること:

1. アプリを開ける。
2. 内蔵サンプルを読み込める。
3. `?id=001` を直接開ける。
4. `?id=002` を直接開ける。
5. 縦表示を開ける。
6. 横表示を開ける。
7. ロード画面へ戻れる。
8. 画面全体に横スクロールが出ない。
9. 重大なエラー表示や真っ白な画面にならない。

可能であれば次の端末またはブラウザでも確認する。

- PC ChromeまたはEdge
- Android Chrome
- AndroidタブレットまたはWindowsタブレット
- iPhone Safari

iPhone Safariは第10段階時点では未確認のため、教室でiPhoneを使う可能性がある場合は優先して確認する。

## 4. 練習画面の確認

縦表示と横表示の両方で確認する。

確認すること:

1. 再生、一時停止、先頭、シークが動作する。
2. 再生速度を変更できる。
3. メトロノームON/OFF、音量、プリカウントを設定できる。
4. 縦表示で白鍵幅、譜面横位置、音価の幅を調整できる。
5. 横表示で五線間隔、譜面縦位置、音価の幅を調整できる。
6. 縦表示と横表示を切り替えても、同じ曲として理解できる。
7. ド♯とレ♭の違いが、縦表示と横表示でこれまで通り保持されている。
8. 音名と指番号が表示される。

注意: 第10段階時点では、音名と指番号のON/OFF切替UIは未実装である。教室試用前に切替が必須か、常時表示で十分かを確認する。

## 5. 保存とJSON入出力の確認

確認すること:

1. 楽曲を端末内へ保存できる。
2. 保存一覧から読み込める。
3. 削除確認が表示され、削除できる。
4. JSONを書き出せる。
5. 書き出したJSONを再読み込みできる。
6. 端末内保存が、その端末・そのブラウザ内だけの保存だと理解できる。

## 6. 教室試用前の確認

教室で先生や生徒に見せる前に、次を確認する。

1. 先生がロード画面から課題を選べる。
2. 先生が縦表示と横表示を切り替えられる。
3. 先生が表示調整モードを開閉できる。
4. スマートフォンまたはタブレットを鍵盤付近へ置いたとき、実鍵盤との位置合わせを説明できる。
5. 操作に迷った場合でも、ロード画面へ戻れる。
6. 試用中に記録する内容を `docs/classroom-trial-notes-template.md` で確認している。
7. 先生へ、MVPでは演奏判定、採点、ピアノ音源再生、クラウド同期は行わないことを説明できる。

## 7. 確認結果の伝え方

次の形式で設計スレッドへ伝える。

```text
1. アプリを開ける: はい / いいえ
2. 内蔵サンプルを読み込める: はい / いいえ
3. 縦表示の基本操作: 問題なし / 問題あり
4. 横表示の基本操作: 問題なし / 問題あり
5. 表示調整: 問題なし / 問題あり
6. メトロノーム・プリカウント: 問題なし / 問題あり
7. 端末内保存: 問題なし / 問題あり
8. JSON書き出し・再読み込み: 問題なし / 問題あり
9. スマートフォン表示: 問題なし / 問題あり / 未確認
10. タブレット表示: 問題なし / 問題あり / 未確認
11. iPhone Safari表示と音: 問題なし / 問題あり / 未確認
12. MVP readinessの要注意事項を確認した: はい / いいえ
13. 教室で先生に説明できそうか: はい / いいえ
14. 教室試用に進めそうか: はい / いいえ

使用したPCブラウザ:
使用したスマートフォン:
使用したタブレット:
使用したiPhone:
分かりにくかったところ:
改善してほしいところ:
教室試用前に不安なところ:
```

「問題あり」または「いいえ」がある場合は、端末、画面、操作手順、期待した状態、実際の状態を分かる範囲で書く。
