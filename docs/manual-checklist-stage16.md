# 第16〜16.5段階 手動確認チェックリスト

第16段階では、ホーム画面を「すぐ使う曲だけ」に保ち、曲カタログを全教材一覧として使えるかを確認する。第16.5段階では、曲カタログがスマートフォンでも読みやすいカードUIになっているかを確認する。

## 1. ホーム画面

- [ ] ホーム画面の「曲を選ぶ」に `001`〜`006` が表示される。
- [ ] ホーム画面の通常の曲選択に `901` と `902` が表示されない。
- [ ] 「曲カタログ」リンクから `catalog.html` へ移動できる。
- [ ] スマートフォン幅でも、曲選択、ピアノ表示、スコア表示、曲カタログリンクが操作できる。
- [ ] ページ全体に横スクロールが出ない。

## 2. 曲カタログ

- [ ] `catalog.html` に `001`〜`006`、`901`、`902` が表示される。
- [ ] `901` と `902` が「開発確認」または同等のグループとして分かる。
- [ ] `901` と `902` のホーム表示状態が「カタログのみ」と分かる。
- [ ] `catalog.html` の「ホームへ戻る」からアプリ本体のホームへ戻れる。
- [ ] スマートフォン幅では、曲が1列のカードとして表示され、ページ全体の横スクロールは出ない。
- [ ] スマートフォン幅で、長い説明文や直接URL例がカード外へはみ出さない。
- [ ] 直接URL例は折りたたみ内で確認でき、閉じた状態では曲を探して「開く」操作を優先して見られる。
- [ ] PC幅またはタブレット幅では、曲カードが画面幅に応じて2列または3列程度に並び、読みづらくならない。

## 3. 直接URL

- [ ] `?id=901` で「ドからソまで」を開ける。
- [ ] `?id=902` で「ド♯とレ♭」を開ける。
- [ ] 直接URLで開いたホーム非表示曲が、現在選択中の曲として表示される。
- [ ] 直接URLで開いたホーム非表示曲から、ピアノ表示へ進める。
- [ ] 直接URLで開いたホーム非表示曲から、スコア表示へ進める。
- [ ] catalogの「開く」リンクから `901`、`902` を開ける。

## 4. 既存機能の維持

- [ ] `001`〜`006` は従来どおりホームから選んで開ける。
- [ ] 保存曲の選択、読み込み、削除が壊れていない。
- [ ] データ管理を開くと、JSON貼り付け、JSONファイル読み込み、JSON書き出し、端末内保存へ到達できる。
- [ ] ピアノ表示、スコア表示、再生、シーク、メトロノーム、プリカウントが壊れていない。
