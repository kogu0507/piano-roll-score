## 1. この確認の目的

横表示で、五線の大きさと譜面の縦位置を見やすく調整できるか確認する。

この確認では、楽譜の専門知識は必要ない。見やすくなったか、操作が分かりやすいか、スマートフォンでも使えるかを確認する。

## 2. PCでの確認

設計スレッドまたは実装スレッドが起動した画面を使用する。

通常は次のようなURLになる。

```text
http://127.0.0.1:5173/app/piano-roll-score/?id=001
```

### 手順1: 横表示を開く

ロード画面で「横表示を確認」を押す。

正常な状態:

- 横表示画面が開く。
- 曲名が表示される。
- 五線、補助グリッド、音符ブロックが表示される。
- 五線間隔と譜面縦位置の調整欄が表示される。

確認すること:

- 調整欄の名前を見て、何を調整するものか分かるか。
- 文字やボタンが小さすぎないか。

### 手順2: 五線間隔を調整する

「五線の1間の幅」または同等のスライダーを動かす。

正常な状態:

- 五線の線と線の間隔が変わる。
- 音符ブロックも五線に合わせて上下位置が変わる。
- 音符ブロックの大きさも不自然にならない。
- 補助グリッドや補助線も破綻しない。
- ド♯とレ♭の上下位置の違いが維持される。

確認すること:

- 広げると見やすくなるか。
- 狭くしても画面が崩れないか。
- 初心者、子供、高齢者向けに役立ちそうか。

### 手順3: 譜面の縦位置を調整する

「譜面の縦位置」または同等のスライダーを動かす。

正常な状態:

- 五線、補助線、音符ブロックが一緒に上下へ移動する。
- 音符同士の上下関係は変わらない。
- ページ全体ではなくCanvas内の譜面だけが移動する。

次に「中央に戻す」または同等のボタンを押す。

正常な状態:

- 譜面が見やすい中央付近へ戻る。

確認すること:

- 右手だけ、左手だけ、特定音域だけを見やすい位置へ置く操作として使えそうか。
- 縦位置と五線間隔の違いが分かりやすいか。

### 手順4: 縦表示・ロード画面との往復

横表示から縦表示へ切り替え、もう一度横表示へ戻る。

次にロード画面へ戻る。

正常な状態:

- 縦表示と横表示の切り替えが動作する。
- ロード画面へ戻ってもJSONと検証結果が残っている。
- 画面全体に横スクロールが発生しない。

## 3. スマートフォンでの簡易確認

スマートフォンで同じ画面を開く。

1. 「横表示を確認」を押す。
2. 五線間隔を調整する。
3. 譜面縦位置を調整する。
4. 可能なら横向きと縦向きの両方を見る。

確認すること:

- スライダーやボタンを指で操作しやすいか。
- 五線間隔を広げると見やすくなるか。
- 譜面縦位置を動かして、必要な場所を見やすくできるか。
- 画面全体に横スクロールが発生しないか。
