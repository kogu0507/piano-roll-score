## 1. この確認の目的

縦表示と横表示で、同じ曲が同じ再生位置を使って自然に流れるか確認する。

この段階では音は鳴らない。メトロノーム、プリカウント、演奏判定もまだ確認しない。見るべき点は、音符の流れ方、操作の分かりやすさ、縦横切り替え時の現在位置である。

## 2. PCでの確認

設計スレッドまたは実装スレッドが起動した画面を使用する。

通常は次のようなURLになる。

```text
http://127.0.0.1:5173/app/?id=001
```

### 手順1: 縦表示で再生する

ロード画面で「縦表示を確認」を押す。

正常な状態:

- 縦表示画面が開く。
- スタート、一時停止、先頭に戻す、シーク、再生速度の操作欄が表示される。
- 現在位置と曲全体の長さが表示される。

「スタート」を押す。

正常な状態:

- 音符ブロックが上から下へ流れる。
- 現在位置の表示が進む。
- 音符の開始位置が判定ラインへ近づいていく。

確認すること:

- 流れる速さが見やすいか。
- スタートボタンの意味が分かりやすいか。
- 音が鳴らなくても、動きとして理解できるか。

### 手順2: 一時停止と先頭に戻す

再生中に「一時停止」を押す。

正常な状態:

- 音符の動きが止まる。
- 現在位置も止まる。

もう一度「スタート」を押す。

正常な状態:

- 止まった付近から再開する。

次に「先頭に戻す」を押す。

正常な状態:

- 現在位置が先頭へ戻る。
- 表示も先頭の状態へ戻る。

確認すること:

- 停止と再開が自然か。
- 先頭に戻す操作が予想どおりか。

### 手順3: シークする

シークのスライダーまたは入力を動かす。

正常な状態:

- 現在位置が変わる。
- Canvasの音符位置も変わる。
- 縦表示の白鍵幅や横位置の調整とは別の操作だと分かる。

確認すること:

- 「曲の現在位置」を動かしていると分かるか。
- 鍵盤幅や譜面位置の調整と混同しないか。

### 手順4: 再生速度を変える

再生速度を変更する。

正常な状態:

- 速度表示が変わる。
- 再生中の場合、音符の流れる速さが変わる。

確認すること:

- 速すぎたり遅すぎたりしない範囲か。
- 初心者向けに遅くできることが役立ちそうか。

### 手順5: 横表示へ切り替える

再生中または一時停止中に、横表示へ切り替える。

正常な状態:

- 横表示画面が開く。
- 可能な限り同じ現在位置が維持される。
- 横表示では音符ブロックが右から左へ流れる。
- スタート、一時停止、先頭に戻す、シーク、再生速度を引き続き操作できる。

確認すること:

- 縦表示と同じ曲の同じ場所を見ていると分かるか。
- 横表示の流れ方が自然か。

### 手順6: ロード画面へ戻る

ロード画面へ戻る。

正常な状態:

- ロード画面へ戻る。
- JSONと検証結果が残っている。

## 3. スマートフォンでの簡易確認

スマートフォンで同じ画面を開く。

1. 縦表示を開く。
2. スタート、一時停止、先頭に戻すを試す。
3. シークを試す。
4. 横表示へ切り替える。
5. 横表示でもスタート、一時停止、シークを試す。

確認すること:

- ボタンやスライダーを指で操作しやすいか。
- 再生中に画面が崩れないか。
- 画面全体に横スクロールが発生しないか。
- 縦表示の鍵盤幅調整や横表示の五線間隔調整と、シークを混同しないか。
