# Future TODOs

最終更新日: 2026年7月5日

この資料は、第11.5段階で出た改善案を、今回の実装範囲から分離して記録するためのTODOである。以下はMVP公開前のサンプル曲整理では実装しない。

## 1. アウフタクト対応

- 「聖者の行進」など、曲頭が弱起で始まる曲へ対応する。
- 拍線・小節線と合わせて設計する。

## 2. ピアノ表示・スコア表示の拍線

- ピアノ表示にも拍を表す薄い線を出す。
- スコア表示にも拍の把握を助ける線を出す。

## 3. 小節線

- ピアノ表示・スコア表示の両方に、小節線を少し太めに表示する。
- 五線への移行を助ける教育的補助として扱う。

## 4. スコア表示の音名・指番号ラベル左寄せ

- 現在は音符ブロック中央寄せだが、音名情報を早く見られるよう左端寄せを検討する。
- 表示順は `音名 / 指番号 / 右手・左手` を検討する。

## 5. 広い音域、加線、低音域の扱い

- 喜びの歌などで下第2加線のラが出る場合がある。
- スマートフォンでの実鍵盤合わせと、スコア表示の見やすさを両立する方針を検討する。

## 6. 移調版や応用教材の運用方針

- 例: カエルの合唱（ニ長調）など。
- 基本はJSONファイル読み込みで扱い、よく使うものだけ内蔵サンプルへ昇格する。

## 7. 臨時記号付き音符の自動強調

- 五線譜で臨時記号にマーカーを付ける教育実践がある。
- `sharp` / `flat` の音符ブロックを自動で色付けする案を検討する。
- 音符ブロック全体は無彩色寄りにし、臨時記号だけが目立つ配色も候補にする。
