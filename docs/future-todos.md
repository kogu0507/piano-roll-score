## 1. アウフタクト対応

- 状態: 第15段階で実装済み。
- 「聖者の行進」など、曲頭が弱起で始まる曲へ対応できるようにした。
- `pickupBeats` を楽曲全体へ任意項目として追加し、アウフタクト部分は負の `note.time` で表す。
- JSON上の `time: 0` は1小節目1拍目として維持し、アプリ内部では `playbackTime = note.time + pickupBeats` に正規化する。
- 拍線、小節線、メトロノームの拍位置や強拍判定では `scoreTime = playbackTime - pickupBeats` を使う。
- 内蔵サンプル `006: 聖者の行進（アウフタクト）` を追加した。
- 小節番号、拍番号、拍子記号表示は未実装のまま残す。

## 7. 臨時記号付き音符の自動強調

- 状態: 第14段階で実装済み。第14.5段階で音符ブロック本体、手の補助表示、臨時記号強調の視覚上の役割を整理済み。
- 五線譜で臨時記号にマーカーを付ける教育実践に合わせ、`sharp` / `flat` の音符ブロックを自動強調する。
- 音符ブロック全体を派手に塗り分けるのではなく、細い左端帯と少し濃い枠線で軽く強調する。音名表示OFF時だけ、小さな `♯` / `♭` マーカー文字も表示する。
- 第14段階補正で色の意味づけを見直し、`sharp` はオレンジ/アンバー系の暖色、`flat` は青/青紫系の寒色で区別する。
- 将来、利用者確認で表示が邪魔になる場合は、表示ON/OFF設定を検討する。
