# 第18段階 手動確認チェックリスト

対象: 教室コード入力と教室カタログ画面の入口

## 1. 教室コード入力

- [ ] ホーム画面の「データ管理」を開くと「教室コードで開く」が表示される。
- [ ] `demo` を入力して「教室カタログを開く」を押すと、デモ教室カタログが表示される。
- [ ] ` demo ` のように前後空白があっても読み込める。
- [ ] `DEMO` のように大文字でも読み込める。
- [ ] `ＤＥＭＯ` のような代表的な全角英数字でも読み込める。
- [ ] 空欄で押すと、教室コード入力を促すエラーが出る。
- [ ] `さくら` や `abc def` のような不正文字を含むコードは、回復可能なエラーになる。

## 2. 教室カタログ画面

- [ ] 読み込み成功後、画面内に「教室カタログ」と分かる見出しがある。
- [ ] 教室名、カタログ名、更新日が表示される。
- [ ] グループ見出しごとに、1列カードで曲が表示される。
- [ ] 各カードにID、曲名、説明、level、グループ、開く操作が表示される。
- [ ] 「ホームへ戻る」でホーム側へ戻れる。
- [ ] スマートフォン幅でも横スクロールが発生しない。

## 3. 曲を開く

- [ ] `demo-001` を開くと、曲JSONが読み込まれ、ピアノ表示へ進める。
- [ ] `demo-902` を開くと、曲JSONが読み込まれ、スコア表示へ進める。
- [ ] JSON編集欄にも読み込んだ曲JSONが反映される。
- [ ] 既存の音名・指番号表示、臨時記号強調、拍線・小節線が壊れていない。

## 4. URLパラメータ

- [ ] `?classroom=demo` で開くと、デモ教室カタログが初期読み込みされる。
- [ ] `?catalog=./data/classroom-catalogs/demo/catalog.json` は引き続き動く。
- [ ] `?id=001` と `?id=902` は引き続き既存どおり曲を直接開ける。

## 5. 本番想定URLとエラー

- [ ] `demo` 以外の有効な教室コードでは、サイトルート配下の `/data/piano-roll-score/classroom-catalogs/{hash}/catalog.json` を読みに行く。
- [ ] 存在しない教室コードでは「教室カタログが見つかりません。教室コードを確認してください。」方向のエラーになる。
- [ ] 通信失敗や壊れたJSONでもアプリ全体が止まらない。

## 6. 今回実装しないことの確認

- [ ] 教室コードはログイン認証ではないことを前提として確認する。
- [ ] 教室コード履歴保存、最近使った教室、お気に入りはまだない。
- [ ] 検索・フィルター、先生用管理画面、クラウド同期はまだない。
- [ ] 実際の本番教室データ配置、公開用フォルダコピー、FTPアップロードはこの段階では行わない。
