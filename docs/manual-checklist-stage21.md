# 第21段階 手動確認チェックリスト

第21段階では、左手単独教材と低音部スコア表示を確認する。

## 前提

- 公開想定パス: `/app/piano-roll-score/`
- 代表曲: `007: カエルの合唱 左手`
- 既存確認曲: `002: カエルの合唱`, `902: ド♯とレ♭`

## ホームとカタログ

- [ ] ホームの曲選択に `カエルの合唱 左手` が表示される。
- [ ] `?id=007` で `カエルの合唱 左手` が直接開ける。
- [ ] 曲詳細にヘ音記号相当の情報が表示され、左手教材だと分かる。
- [ ] `catalog.html` に `007` が表示される。
- [ ] `catalog.html` の `007` からホームへ戻り、曲を開ける。
- [ ] `?classroom=demo` の教室カタログに左手教材カードが表示される。
- [ ] 教室カタログの左手教材カードから直接 `ピアノ表示` と `スコア表示` へ進める。

## ピアノ表示

- [ ] `?id=007` からピアノ表示へ進める。
- [ ] 音符が低音域C3〜A3の鍵盤位置へ流れる。
- [ ] 音符ブロックに左手の補助表示が出る。
- [ ] 白鍵1鍵の幅を変えると、低音域の鍵盤幅と音符位置が追従する。
- [ ] 譜面の横位置を変えると、実鍵盤に合わせて左右へ移動できる。
- [ ] 右手版 `002` のピアノ表示が従来どおり使える。

## スコア表示

- [ ] `?id=007` からスコア表示へ進める。
- [ ] 音符が低音部譜表として自然な上下位置に表示される。
- [ ] 左手の補助表示が、音名・指番号・臨時記号の表示と干渉しない。
- [ ] 五線の1間の幅、譜面の縦位置、音価の幅の調整が従来どおり使える。
- [ ] `902: ド♯とレ♭` のスコア表示で、臨時記号強調と左寄せラベルが壊れていない。

## 端末別

- [ ] PC幅で横スクロールが出ない。
- [ ] スマートフォン縦向き相当で横スクロールが出ない。
- [ ] スマートフォン横向き相当でピアノ表示のCanvasが圧迫されすぎない。
- [ ] AndroidタブレットまたはWindowsタブレット相当で、ピアノ表示・スコア表示・教室カタログが崩れない。
