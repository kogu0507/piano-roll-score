# 第17段階 手動確認チェックリスト

対象: 外部/教室カタログ読み込み基盤

## 確認環境

- PCブラウザ:
- Androidスマートフォン:
- タブレット:

## ホーム画面

- [ ] 「データ管理」を開くと「教室カタログを読み込む」が見える。
- [ ] URL入力欄に `./data/classroom-catalogs/demo/catalog.json` を入力して読み込める。
- [ ] デモ教室 / 教室カタログ確認用 が表示される。
- [ ] 右手、開発確認などのグループでカードが表示される。
- [ ] スマートフォン幅で横スクロールが出ない。

## 曲読み込み

- [ ] `demo-001` の「開く」から曲JSONが読み込まれる。
- [ ] 読み込んだ曲JSONがJSON編集欄に反映される。
- [ ] 読み込み後にピアノ表示へ進める。
- [ ] 読み込み後にスコア表示へ進める。
- [ ] `demo-902` で臨時記号付き音符の表示確認に使える。

## URLパラメータ

- [ ] `?catalog=./data/classroom-catalogs/demo/catalog.json` で開くと、データ管理が開いてカタログが読み込まれる。
- [ ] `?id=001`、`?id=902` の既存直接URL読み込みが壊れていない。

## エラー

- [ ] 存在しないcatalog URLで、回復可能なエラーが表示される。
- [ ] 壊れたcatalog JSONでも、ホーム画面全体は停止しない。
- [ ] 危険な `songUrl` は拒否される。

## 未実装確認（第17段階時点）

- [ ] 教室コード入力欄は追加されていない。
- [ ] ログイン、サーバー認証、クラウド同期、先生用管理画面は追加されていない。
- [ ] 外部カタログの曲を読み込んだだけでは、端末内保存へ自動保存されない。

# 補足: 第18段階への引き継ぎ

第17段階のURL直接入力は、開発確認・運用確認用の入口として維持する。第18段階では別途、教室コードを正規化・ハッシュ化して同じ外部カタログ読み込み処理へ接続する入口を追加する。第18段階の確認は `docs/manual-checklist-stage18.md` を参照する。
