## 1. この確認の目的

縦表示の静止プレビューが見やすく、白鍵幅と横位置を迷わず調整できるか確認する。

この確認では、プログラムの仕組みやCanvasを理解する必要はない。操作しにくい、表示が不自然、意味が分からないと感じた場合は、それ自体が重要な結果である。

## 2. PCでの確認

設計スレッドが起動した次の画面を使用する。

```text
http://127.0.0.1:5173/app/?id=001
```

画面を開けない場合は、無理に設定を変更せず、表示された内容を設計スレッドへ伝える。

### 手順1: 縦表示を開く

ロード画面の「楽曲JSON編集」欄にある「縦表示を確認」を押す。

正常な状態:

- 「ドからソまで」という曲名が表示される
- 「静止プレビュー」と表示される
- 白鍵幅と横位置の調整欄が表示される
- Canvas内にド、レ、ミ、ファ、ソの音符ブロックが表示される
- Canvas下部に白鍵と黒鍵のガイドが表示される
- 鍵盤ガイドの上端に赤い判定ラインが表示される
- 画面全体に横スクロールが発生しない

確認すること:

- 音符、鍵盤、判定ラインの関係を見て理解できそうか
- 文字やボタンが小さすぎないか
- 説明文が分かりにくくないか
- 不要な左右余白が目立たないか

### 手順2: 白鍵幅を変更する

「白鍵1鍵の幅」のスライダーを左右へ動かす。

正常な状態:

- `225 px` などの数値が変わる
- 音符ブロックと鍵盤ガイドの幅がすぐ変わる
- 画面全体ではなく、Canvas内で表示が収まる

次に「画面幅に合わせる」を押す。

正常な状態:

- ドからソまでの課題音域がCanvas幅へ合う
- 課題音域が中央付近へ戻る

確認すること:

- スライダーの目的が分かるか
- 実鍵盤の幅へ合わせる操作として使えそうか
- 「画面幅に合わせる」の動作が予想しやすいか

### 手順3: 横位置を変更する

「譜面の横位置」のスライダーを左右へ動かす。

正常な状態:

- `0 px` などの数値が変わる
- 音符ブロックと鍵盤ガイドが一緒に左右へ移動する
- ページ全体は左右へ移動しない

次に「中央に戻す」を押す。

正常な状態:

- 課題音域が中央付近へ戻る

確認すること:

- 白鍵幅の変更と横位置の変更を区別できるか
- 微調整に十分な細かさだと感じるか

### 手順4: Canvasをドラッグする

Canvasの音符がない場所を、マウスで左右へドラッグする。

正常な状態:

- 音符ブロックと鍵盤ガイドがドラッグ方向へ移動する
- 「譜面の横位置」の数値とスライダーも変わる
- 上下スクロールや他の操作が不自然に妨げられない

確認すること:

- ドラッグできることに気付けるか
- 動きが速すぎたり遅すぎたりしないか

### 手順5: ロード画面へ戻る

画面上部の「ロード画面へ戻る」を押す。

正常な状態:

- ロード画面へ戻る
- 「ドからソまで」のJSONと「JSONは有効です。」という結果が残っている

### 手順6: ド♯とレ♭を確認する

「ド♯とレ♭」の「JSON欄に読み込む」を押し、続けて「縦表示を確認」を押す。

正常な状態:

- ド♯とレ♭の音符ブロックが同じ横位置に表示される
- 2つのブロックには、それぞれ「ド♯」「レ♭」と異なる音名が表示される
- 2つのブロックは時間方向に上下へ並ぶ
- 黒鍵ガイドの位置と音符ブロックの横位置が一致する

確認すること:

- 同じ鍵盤位置だと理解できるか
- ド♯とレ♭の表記を区別できるか

## 4. スマートフォンと実鍵盤での確認

### 4.1 接続方法

1. PCを起動したままにする。
2. スマートフォンをPCと同じWi-Fiへ接続する。
3. スマートフォンのSafariまたはChromeを開く。
4. アドレス欄へ次のURLを正確に入力する。

```text
http://192.168.0.162:5173/app/?id=001
```

検索欄ではなく、画面上部のアドレス欄へ入力する。PCをスリープさせたり、開発サーバーを停止したりすると接続できなくなる。

接続できない場合は、設定を変更せず、ブラウザに表示された文を設計スレッドへ伝える。Wi-Fiの端末間通信またはWindowsファイアウォールが原因の場合は、別の接続方法を案内する。

### 4.2 端末の向き

「縦表示」は音符が上から下へ進む表示方式を意味し、スマートフォンを必ず縦向きにするという意味ではない。

- 最初はスマートフォンを横向きにする。
- 画面回転が固定されている場合は、一時的に回転できる状態にする。
- 横向きは画面の横幅を広く使えるため、6度程度の課題音域を実鍵盤へ合わせやすい。
- 横向きの確認後、余裕があれば縦向きでも操作不能にならないか確認する。

### 4.3 実鍵盤への置き方

1. ロード画面で「縦表示を確認」を押す。
2. スマートフォンを落下しない安定した場所へ置く。
3. Canvas下部の白鍵ガイドが実鍵盤と同じ方向に並ぶようにする。
4. 「白鍵1鍵の幅」を動かし、画面上の白鍵1鍵分と実鍵盤の白鍵1鍵分を合わせる。
5. 幅が合ったら「譜面の横位置」を動かすか、Canvasを左右へドラッグする。
6. 画面上のド、レ、ミ、ファ、ソの位置が、対応させたい実鍵盤の位置へ合うか確認する。

スマートフォンを鍵盤の上へ直接置いて演奏を妨げたり、落下しやすい位置へ置いたりしない。譜面台、鍵盤奥の平らな部分、安定したスマートフォンスタンドなどを使用する。

主に次を確認する。

- スマートフォンを鍵盤付近へ無理なく置けるか
- 白鍵幅を実鍵盤へ合わせられるか
- 横位置を実鍵盤へ合わせられるか
- 6度程度の狭い課題音域で不要な左右余白を抑えられるか
- タッチ操作で幅変更と横位置変更を行いやすいか
- 横向きの画面で表示が見やすいか
- 端末を回転してもCanvasが正しく描画されるか
