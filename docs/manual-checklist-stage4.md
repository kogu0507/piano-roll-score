# 第4段階 ユーザー確認手順

確認状態: PC確認待ち。スマートフォンと実鍵盤での確認は、PC確認後に行う。

## 1. この確認の目的

縦表示の静止プレビューが見やすく、白鍵幅と横位置を迷わず調整できるか確認する。

この確認では、プログラムの仕組みやCanvasを理解する必要はない。操作しにくい、表示が不自然、意味が分からないと感じた場合は、それ自体が重要な結果である。

## 2. PCでの確認

設計スレッドが起動した次の画面を使用する。

```text
http://127.0.0.1:5173/app/?id=001
```

画面を開けない場合は、無理に設定を変更せず、表示された内容を設計スレッドへ伝える。

### 手順1: 縦表示を開く

ロード画面の「楽曲JSON編集」欄にある「縦表示を確認」を押す。

正常な状態:

- 「ドからソまで」という曲名が表示される
- 「静止プレビュー」と表示される
- 白鍵幅と横位置の調整欄が表示される
- Canvas内にド、レ、ミ、ファ、ソの音符ブロックが表示される
- Canvas下部に白鍵と黒鍵のガイドが表示される
- 鍵盤ガイドの上端に赤い判定ラインが表示される
- 画面全体に横スクロールが発生しない

確認すること:

- 音符、鍵盤、判定ラインの関係を見て理解できそうか
- 文字やボタンが小さすぎないか
- 説明文が分かりにくくないか
- 不要な左右余白が目立たないか

### 手順2: 白鍵幅を変更する

「白鍵1鍵の幅」のスライダーを左右へ動かす。

正常な状態:

- `225 px` などの数値が変わる
- 音符ブロックと鍵盤ガイドの幅がすぐ変わる
- 画面全体ではなく、Canvas内で表示が収まる

次に「画面幅に合わせる」を押す。

正常な状態:

- ドからソまでの課題音域がCanvas幅へ合う
- 課題音域が中央付近へ戻る

確認すること:

- スライダーの目的が分かるか
- 実鍵盤の幅へ合わせる操作として使えそうか
- 「画面幅に合わせる」の動作が予想しやすいか

### 手順3: 横位置を変更する

「譜面の横位置」のスライダーを左右へ動かす。

正常な状態:

- `0 px` などの数値が変わる
- 音符ブロックと鍵盤ガイドが一緒に左右へ移動する
- ページ全体は左右へ移動しない

次に「中央に戻す」を押す。

正常な状態:

- 課題音域が中央付近へ戻る

確認すること:

- 白鍵幅の変更と横位置の変更を区別できるか
- 微調整に十分な細かさだと感じるか

### 手順4: Canvasをドラッグする

Canvasの音符がない場所を、マウスで左右へドラッグする。

正常な状態:

- 音符ブロックと鍵盤ガイドがドラッグ方向へ移動する
- 「譜面の横位置」の数値とスライダーも変わる
- 上下スクロールや他の操作が不自然に妨げられない

確認すること:

- ドラッグできることに気付けるか
- 動きが速すぎたり遅すぎたりしないか

### 手順5: ロード画面へ戻る

画面上部の「ロード画面へ戻る」を押す。

正常な状態:

- ロード画面へ戻る
- 「ドからソまで」のJSONと「JSONは有効です。」という結果が残っている

### 手順6: ド♯とレ♭を確認する

「ド♯とレ♭」の「JSON欄に読み込む」を押し、続けて「縦表示を確認」を押す。

正常な状態:

- ド♯とレ♭の音符ブロックが同じ横位置に表示される
- 2つのブロックには、それぞれ「ド♯」「レ♭」と異なる音名が表示される
- 2つのブロックは時間方向に上下へ並ぶ
- 黒鍵ガイドの位置と音符ブロックの横位置が一致する

確認すること:

- 同じ鍵盤位置だと理解できるか
- ド♯とレ♭の表記を区別できるか

## 3. PC確認結果の伝え方

次の形式で設計スレッドへ伝える。

```text
1. 縦表示の最初の見え方: 問題なし / 問題あり
2. 白鍵幅の調整: 問題なし / 問題あり
3. 横位置の調整: 問題なし / 問題あり
4. Canvasのドラッグ: 問題なし / 問題あり
5. ロード画面へ戻る: 問題なし / 問題あり
6. ド♯とレ♭の表示: 問題なし / 問題あり

分かりにくかったところ:

改善してほしいところ:
```

「問題あり」の場合は、次も分かる範囲で伝える。

- どの手順で起きたか
- 押したボタンや行った操作
- 期待していた結果
- 実際に起きた結果
- 使用したブラウザ

画面のスクリーンショットを添付してもよい。

## 4. スマートフォンと実鍵盤での確認

PC確認が完了した後に行う。

主に次を確認する。

- スマートフォンを鍵盤付近へ無理なく置けるか
- 白鍵幅を実鍵盤へ合わせられるか
- 横位置を実鍵盤へ合わせられるか
- 6度程度の狭い課題音域で不要な左右余白を抑えられるか
- タッチ操作で幅変更と横位置変更を行いやすいか
- 縦向きの画面で表示が見やすいか

接続URL、開き方、詳しい操作手順は、PC確認後に設計スレッドが案内する。
