# 第22段階 手動確認チェックリスト

第22段階では、右手版・左手版・将来の両手版や分割練習版を、カタログ上で選びやすくするための表示整理を確認する。

## 1. 通常カタログ

- [ ] `catalog.html` を開ける。
- [ ] 「カエルの合唱」セクションに、`002: カエルの合唱` と `007: カエルの合唱 左手` がまとまって表示される。
- [ ] `002` のカードに「右手」など右手版と分かる表示がある。
- [ ] `007` のカードに「左手 Lv.1」など左手版と分かる表示がある。
- [ ] 各カードの「開く」リンクから該当曲を開ける。
- [ ] `901`、`902` など開発確認曲もカタログに残っている。

## 2. 教室カタログ

- [ ] `?classroom=demo` でデモ教室カタログを開ける。
- [ ] 「カエルの合唱」まとまりの中に「カエルの合唱 右手」と「カエルの合唱 左手」が表示される。
- [ ] 右手版カードから「ピアノ表示」へ直接進める。
- [ ] 左手版カードから「スコア表示」へ直接進める。
- [ ] 必要に応じて「JSONを確認」から曲JSONを確認できる。

## 3. スマートフォン幅

- [ ] 390px前後のスマートフォン幅で横スクロールが出ない。
- [ ] シリーズ見出し、曲名、説明、バッジが読みにくくない。
- [ ] 「ピアノ表示」「スコア表示」ボタンが押しやすい。
- [ ] カード同士が重なったり、バッジが過剰に詰まったりしない。

## 4. 既存互換性

- [ ] `?id=001`〜`?id=007` を直接開ける。
- [ ] `?id=901`、`?id=902` を直接開ける。
- [ ] ホーム画面のサンプル曲選択から従来どおりピアノ表示・スコア表示へ進める。
- [ ] `?catalog=./data/classroom-catalogs/demo/catalog.json` が従来どおり動く。
- [ ] JSON貼り付け、JSONファイル読み込み、JSON書き出し、端末内保存が壊れていない。

## 5. 注意して見る点

- 教材バリエーションはカタログ上の見せ方であり、楽曲JSON形式そのものは変えていない。
- 第22段階では、既存IDの大規模リネーム、両手同時表示、大譜表、検索・フィルターUIは実装していない。
- 実際の運営教材カタログでは、`docs/classroom-catalog-operations.md` のID方針に沿って4桁IDを検討する。
