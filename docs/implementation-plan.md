## 4. 第6段階の目的

第6段階の目的は、静止プレビューを「流れる譜面」へ変えることである。

具体的には次を実現する。

- 縦表示で音符ブロックが上から下へ流れる。
- 横表示で音符ブロックが右から左へ流れる。
- 縦表示と横表示で同じ楽曲、同じ現在位置、同じ再生状態を共有する。
- スタート、一時停止、先頭に戻す、シーク、再生速度変更を行える。
- 表示方向を切り替えても、可能な限り現在位置を維持する。

## 5. 再生タイムライン

### 5.1 基本単位

- 内部の再生位置は拍単位の `currentBeat` とする。
- 曲全体の長さは、各音符の `time + duration` の最大値から求める。
- 秒と拍の変換は `bpm` と再生速度倍率から計算する。
- 再生速度倍率は、BPMそのものを書き換えず、再生位置の進み方に掛ける。

推奨する計算:

```text
beatsPerSecond = bpm / 60 * playbackRate
nextBeat = startBeat + elapsedSeconds * beatsPerSecond
```

フレーム数で再生位置を進めない。`performance.now()` などの経過時間から計算する。

### 5.2 再生状態

少なくとも次を区別する。

- 停止
- 再生中
- 一時停止
- 終了

この段階ではプリカウント状態は作らない。プリカウントは第7段階で扱う。

### 5.3 終了処理

- `currentBeat` が曲の終端へ到達したら再生を終了する。
- 終了時は `currentBeat` を曲の終端に丸める。
- もう一度スタートした場合に、先頭から始めるか、終了位置から再開しないようにする。
- 「先頭に戻す」は、再生中でも停止中でも `currentBeat = 0` に戻す。

## 6. 描画への反映

### 6.1 縦表示

縦表示では、現在位置に合わせて音符ブロックが下方向へ流れる。

既存の静止プレビューでは、0拍を現在位置として描画している。第6段階では `currentBeat` を描画計算へ渡す。

基準:

```text
noteBottomY = judgmentLineY - (note.time - currentBeat) * pixelsPerBeat
noteHeight = note.duration * pixelsPerBeat
noteTopY = noteBottomY - noteHeight
```

`note.time === currentBeat` の音符開始位置が判定ラインへ来る。

### 6.2 横表示

横表示では、現在位置に合わせて音符ブロックが左方向へ流れる。

基準:

```text
noteLeftX = judgmentLineX + (note.time - currentBeat) * pixelsPerBeat
noteWidth = note.duration * pixelsPerBeat
noteRightX = noteLeftX + noteWidth
```

`note.time === currentBeat` の音符開始位置が判定ラインへ来る。

### 6.3 共通化

- 縦表示と横表示で別々の再生位置を持たない。
- 再生位置、曲の終端、再生速度、状態遷移は共通のモデルに置く。
- Canvas描画は既存の縦横レイアウト計算へ `currentBeat` を渡す形を優先する。
- 再生状態の管理をCanvas描画コードへ直接埋め込まない。

## 7. UI要件

譜面表示画面に、少なくとも次を追加する。

- スタート
- 一時停止
- 先頭に戻す
- シーク
- 現在位置表示
- 曲全体の長さ表示
- 再生速度

### 7.1 スタート／一時停止

- 停止中または一時停止中は「スタート」を押せる。
- 再生中は「一時停止」を押せる。
- ボタン名は利用者が次に起こることを理解しやすい日本語にする。
- 再生中に縦表示と横表示を切り替えても、可能な限り同じ位置で再生を続ける。

### 7.2 先頭に戻す

- 「先頭に戻す」を押すと `currentBeat` が0へ戻る。
- 再生中に押した場合は、停止するか、0拍から再生を続けるかを実装上決めてよい。ただし挙動を画面上で不自然にしない。
- 推奨は、先頭に戻して停止する。

### 7.3 シーク

- 曲の任意の拍へ移動できる。
- 単位は拍とする。
- 範囲は0から曲の終端までとする。
- 縦表示の白鍵幅調整、横表示の五線間隔調整とは見た目と名称を明確に分ける。
- シーク中は再生位置とCanvasを即時更新する。
- シーク操作は「譜面位置」や「鍵盤位置」の調整ではなく「曲の現在位置」の操作であることが分かるようにする。

### 7.4 再生速度

- 0.5倍から2.0倍程度の範囲で変更できるようにする。
- 初期値は1.0倍とする。
- 現在値を表示する。
- 変更を再生中にも反映する。
- この段階では速度変更にメトロノーム音を連動させない。メトロノームは第7段階で扱う。

## 8. タブ非表示とリサイズ

- タブがバックグラウンドになった場合、不自然な大ジャンプを避ける。
- 推奨は、タブ非表示時に自動で一時停止する。
- ウィンドウサイズ変更や端末回転時に、現在の `currentBeat` を維持して再描画する。
- シーク、再生速度、縦横切り替え、表示調整の操作を組み合わせても、現在位置が壊れないようにする。

- 横表示または縦表示でスタートできる。
- 再生中に一時停止できる。
- 先頭に戻せる。
- シークするとCanvas表示と現在位置表示が変わる。
- 再生速度を変更できる。
- 縦表示と横表示を切り替えても現在位置が維持される。
- ロード画面へ戻るとJSONと検証結果が保持される。
- 縦表示の白鍵幅・横位置調整とシークを混同しないUIになっている。
- 横表示の五線間隔・譜面縦位置調整とシークを混同しないUIになっている。
- スマートフォン幅でも主要操作ができる。
- ページ全体の横スクロールが発生しない。

Canvasの厳密なピクセル一致を主要判定にしない。時間計算と座標計算は単体テストし、E2Eでは操作と状態表示を中心に確認する。
