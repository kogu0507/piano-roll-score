## 11. 横表示の座標モデル

### 11.1 基本方針

横表示の座標計算は、DOMとCanvasから分離したピュア関数として実装する。

最低限、次を計算できるようにする。

- `spelling` に基づく五線上の縦位置
- 音部記号ごとの基準線
- 五線5本線の位置
- 補助グリッドの位置
- 五線外の補助線
- 音符ブロックの横位置と幅
- 音符ブロックの縦位置
- ♯、♭、音名、指番号の表示情報

縦表示の鍵盤座標とは別モデルである。ただし、楽曲データ、音名表示、時間計算など共有できるロジックは重複実装しない。

### 11.2 時間軸

- 横軸は時間とする。
- 静止プレビューの現在位置は0拍とする。
- 左側に判定ラインを表示する。
- 音符は、将来の再生時に右から左へ流れる前提で配置する。
- 0拍の音符開始位置が判定ラインに一致する。
- `time` が大きい音符ほど右側へ表示する。
- `duration` は音符ブロックの横幅へ変換する。

計算の基準:

```text
noteLeftX = judgmentLineX + time * pixelsPerBeat
noteWidth = duration * pixelsPerBeat
noteRightX = noteLeftX + noteWidth
```

初期値として `pixelsPerBeat` は 96 CSS px 程度を推奨する。実装上の都合で調整してよいが、固定値として分かりやすく管理する。

この段階では表示密度のユーザー調整は実装しない。

### 11.3 五線上の縦位置

横表示の縦位置は `pitch` ではなく `spelling` を基準にする。

音名段階を、C、D、E、F、G、A、B の7段階で扱う。隣り合う音名段階は、五線の「線から隣の間」または「間から隣の線」への移動に対応する。

推奨する基準:

- ト音記号 `treble`: 下第1線を E4、上第5線を F5 とする。
- ヘ音記号 `bass`: 下第1線を G2、上第5線を A3 とする。
- 五線の線間隔は 18 CSS px 程度を初期値とする。
- 隣の音名段階への移動量は線間隔の半分とする。

例:

- ト音記号の E4 は下第1線。
- ト音記号の F4 は下第1線と第2線の間。
- ト音記号の G4 は下第2線。
- C♯4 はCの段へ表示し、♯を表示する。
- D♭4 はDの段へ表示し、♭を表示する。

これにより、C♯4とD♭4は同じ `pitch` でも異なる上下位置になる。

### 11.4 五線と補助グリッド

- 対象の音部記号に対応する5本線を太めに描画する。
- 5本線は補助グリッドより明確に目立たせる。
- 補助グリッドは薄く表示し、五線の認識を邪魔しない。
- 時間方向の縦グリッドは拍単位を基本とする。
- 五線外の音には、必要に応じて短い補助線を表示する。
- 本格的な楽譜組版や符頭の形には寄せすぎない。音符ブロックと五線位置の関係を学ぶ表示を優先する。

## 12. 表示内容

- ♯または♭
